Hello, before you is my Password Account Management System which is an application I made for my Computing Pratcice university module. 

It consists of a HTML file with embedded javascript and a css document which holds the main aesthetic rules regarding the UI's design.

The application has the ability to store usernames and passwords into localstorage, read already stored data from a JSON file or
localstorage, test the strength of a password with a password strength indicator, remember credentials in the form with a remember me
checkbox, and retrieve forgotten usernames and passwords via the forgotten username/password sections of the application. Moreover,
an about, help, and contact section for the application exist for any questions or enquires a user may have.

Hope you, the reader, enjoy having a gander at what I've created and find it to be a useful tool.
